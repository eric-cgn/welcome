The World Wide Web

The World Wide Web (the Web) is made of pages that are linked to one another, kept on servers all over the Internet. You are reading a Web page now. Its protocol is HTTP, so Web addresses begin with http. As you read in Addresses, HTTP stands for Hypertext Transfer Protocol, and hypertext is text with links in it.

Try this

Type http://info.cern.ch/ and press Return.

Mill opens a page from CERN, the physics laboratory in Switzerland where the Web began. From there you can browse a copy of the first Web site.

A little history

Tim Berners-Lee, working at CERN, wrote the first Web server and the first program for reading Web pages in 1990. HTTP is described in RFC 1945, published in 1996.

Pages and links

A Web page is a document, much like one you might write on your Macintosh, with links in it and often pictures. Each link holds the address of another page, a picture, or a file, on the same server or on any other.

Pages are written in HTML, the Hypertext Markup Language: plain text with instructions that tell Mill where the headings, links, and pictures go. To see the HTML of the page you are reading, choose Page Source from the View menu.

Web sites and home pages

A collection of pages kept together by one person or organization is called a Web site. A site's home page is its front page, the one its other pages are reached from.

Mill has a home page too: the page it opens when it starts up, and when you choose Home from the Go menu. To choose your own, choose Preferences from the Edit menu to open Mill's Settings page, type the page's address in Home page, and click Save.

Pictures

Mill shows pictures in the GIF and JPEG formats, among others. Your screen shows black and white, so Mill draws shades of gray as patterns of black and white dots.

Pictures usually take longer to arrive than text. If pages load slowly, you can turn off Load images automatically on the Settings page. A picture then waits until you ask for it: hold the mouse button down on it, and choose Load Image from the menu that appears.

Encryption and proxies

Some sites already use encryption, and the trend is likely to continue. Encryption scrambles the packets between two computers, so that no one along the way can read what they carry. The addresses of encrypted pages begin with https; the s stands for secure.

Working with encryption requires a powerful computer, so many Internet providers also include a service called a proxy. A proxy is a computer that makes requests for you. When you open an https address, Mill sends the request to the proxy, the proxy fetches the page from the encrypted site, and then sends it on to Mill.

To use a proxy, you need its name and port number from your Internet provider. Then:

  1. Choose Preferences from the Edit menu. Mill opens its Settings page.
  2. Under Protocols, find HTTP.
  3. Type the proxy's name, a colon, and its port number in HTTP proxy.
  4. Click the Enable proxy checkbox so that it is checked.
  5. Click Save.

Mill then sends its Web requests through the proxy, except to the names you list in Proxy excluded domains. Without a proxy, Mill can't open https addresses, and tells you it needs one.

Important

Only the part of the trip between the proxy and the site is encrypted. Between your Macintosh and the proxy, everything you send, including passwords, can be read along the way. Send a password through a proxy only if you trust the people who run it.
