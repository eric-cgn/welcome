Electronic Mail

Try this

If your Internet provider gives you an IMAP mail account, type imap://name@server/, using your account's name and the name of your provider's mail server, and press Return. If your account's name is your e-mail address, type the whole e-mail address as the name.

Mill asks for your password, then lists your mailboxes. Click INBOX to see the messages in it, newest first. Messages you haven't read are in bold.

What electronic mail is

Electronic mail, or e-mail, is a message sent from one person to another over the Internet. Your messages wait in a mailbox on your provider's mail server until you read them, much as letters wait in a post office box until you come for them.

The comparison stops when you read your mail. With IMAP, reading a message doesn't take it out of the box: it stays on the server, so you can read it again later, even from another computer.

An e-mail address names a person's mailbox and the server that keeps it, joined by the @ sign, said "at." It isn't the kind of address you type into Mill's address bar: it says where a message should go, not which protocol to use.

A little history

E-mail is older than the Internet. In 1971, Ray Tomlinson sent messages between two computers on the ARPANET, the network the Internet grew from, and chose the @ sign to join a person's name to the name of their computer.

IMAP, the Internet Message Access Protocol, lets a program read mail that stays on the server. Its rulebook is RFC 2060, published in 1996.

What Mill does

While specialized programs exist to manage electronic mail, Mill can read yours. It lists your mailboxes, shows each mailbox's messages a page at a time with the ones you haven't read in bold, and shows each message's text. Pictures and other files attached to a message are named, not shown. Mill can also search a mailbox; plugin://imap/about shows the addresses it takes.

Mill only reads. It doesn't send mail, and it doesn't move or delete messages. Reading a message in Mill doesn't even mark it as read, so it stays unread for the program you use to answer your mail.

Mill logs in to the mail server without encryption. Some mail servers already require encryption; ask your provider whether its server accepts an IMAP login without it.

Important

Mill sends your name and password to the mail server as plain text, so they could be read along the way. Use a password you don't use anywhere else. When you finish, you can choose Clear Logins and Cookies from the Edit menu, and Mill forgets every name and password you have typed.

Good manners

A message can be passed along to anyone in moments. Write each one as if people other than the one you sent it to might read it.

What Mill needs

Mill reads mail with its IMAP Plug-In. To see whether it is installed, type mill://plugins and look for IMAP.

If you read mail from one server, you can save its name:

  1. Choose Preferences from the Edit menu. Mill opens its Settings page.
  2. Under Protocols, find IMAP, and type the server's name in Default server.
  3. Click Save, at the bottom of the page.

Then plugin://imap/about has a form with the server filled in: type your account's name and click Open. Under IMAP, Messages per page sets how many messages each page lists.
