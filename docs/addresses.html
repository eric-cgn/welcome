Addresses

Every page, picture, and file you can reach with Mill has an address. Most addresses tell Mill three things: which protocol to use, which server to ask, and what to ask it for. (A few work a little differently, such as addresses for documents on your own Macintosh. You'll find those in Your Macintosh.)

You have used addresses already, even if you haven't typed one. Each link on a page holds an address, and when you click the link, Mill opens that address.

Try this
  1. Click in the address bar at the top of Mill's window, and select the address that is already there.
  2. Type http://welcome.1in1e6.com/contents.html
  3. Press Return.

Mill opens the Contents page of this guide. To come back to this page, click Addresses in the list.

Reading an address

An address is read from left to right. Here is the one you just typed:

http://welcome.1in1e6.com/contents.html

The protocol. An address begins with the name of a protocol, followed by a colon. As you read in Rules of the Road, a protocol is a set of rules that computers follow to talk to each other. http stands for Hypertext Transfer Protocol, the protocol of the World Wide Web. Hypertext is text with links in it.

The server. Next come two slashes, and after them the name of the server: the computer that has what you want. Here, the server is welcome.1in1e6.com.

What you're asking for. The rest of the address, starting with a slash, tells the server what you would like. It works much like finding a document on your Macintosh by opening one folder after another. Slashes separate the names of folders, and the last name is usually the item itself. In this guide, /contents.html is a file named contents.html, and /images/road.gif is a picture named road.gif in a folder named images.

Unlike the Finder, though, the server decides what each name means, and it doesn't always keep a real folder or file by that name.

Typing addresses

Type an address exactly as you see it. Capital letters don't matter in the server's name, but they can matter in the rest of the address.

Tip

When people read addresses aloud, they sometimes say "backslash" when they mean "slash." The slash (/) leans to the right and usually shares a key with the question mark. The backslash (\) leans to the left and is on a different key. Addresses rarely use it. You may also hear the slash called a forward slash or a stroke. Those are other names for the same character.
