Files

Much of what people share on the Internet is files: programs, documents, pictures, and fonts that you can copy to your Macintosh and keep. The protocol made for this is FTP, the File Transfer Protocol. An FTP server holds folders of files, and anyone it lets in can copy them.

What it is

An FTP server works much like a disk you can open from far away. Mill shows each of its folders as a page, with the size of each file beside it. Click a folder to open it, and click Up, at the top of the page, to go back to the folder that holds it.

Unlike a disk, though, a file can't be opened where it sits. Mill copies it to your Macintosh first. Text and pictures appear in Mill's window, and most other files are saved on your disk.

Logging in

Most FTP servers ask for a name and a password. Public archives let anyone in under the name anonymous, so this is called anonymous FTP. Mill logs in that way for you, unless you give it a name or have saved one for that server.

By custom, the password for anonymous FTP is your e-mail address, so the people who run the server know who is visiting. Mill sends mill@ unless you change it: choose Preferences from the Edit menu, and under FTP, type your address in Anonymous login password.

Saving files

When you click a file Mill can't show, Mill asks where to save it, in the same kind of dialog box you use to save a document. Mill also marks common kinds of file so that the Finder knows which application opens them.

Macintosh files often travel packed in one of two ways. A file whose name ends in .bin is usually in MacBinary, which keeps a Macintosh file together with the information the Finder keeps about it, so that any computer can store it. Mill unpacks MacBinary as it saves, and you get the original file.

A file whose name ends in .hqx is in BinHex, which turns a Macintosh file into plain text, so that it can go where only text can, such as e-mail. Mill marks a BinHex file to open with StuffIt Expander, a separate program that turns it back into the original. Many files are also compressed, packed smaller so that they take less time to copy. Their names often end in .sit, and StuffIt Expander unpacks them too.

A little history

FTP is one of the oldest protocols in use: its first version was written in 1971. The rulebook most computers follow is RFC 959, published in 1985.

What's there

The Info-Mac Archive is a large collection of Macintosh software gathered by volunteers, sorted into folders by kind: games, fonts, tools for disks and files, and many more. Much of it runs on a Compact Macintosh. The copy at ftp.jussieu.fr is kept by LIP6, a computer science laboratory in Paris.

Good manners

Busy archives are often copied to other servers, called mirrors, so that no one server has to carry every visitor. The Info-Mac Archive asks visitors to use its mirrors, and the copy this page's Try this visits is one of them. When an archive lists mirrors, choose one near you.

Many FTP servers let in only so many visitors at a time. If one turns you away, try again later.

Sending files

If you have an account on an FTP server, such as one your school or office gives you, Mill can send files to it too. Type your name and an @ before the server's name, as in ftp://name@server/. Mill asks for your password, and each folder's page ends with a place to choose a file and an Upload button.

Important

FTP sends your name and password as plain text, so they can be read along the way. Use a password you don't use anywhere else.

What Mill needs

Mill speaks FTP with the Internet Services Plug-In, which Easy Install puts in the Mill Plug-Ins folder.

Try this

Type ftp://ftp.jussieu.fr/pub/mac/info-mac/ and press Return.

Mill logs in to the server and shows a folder of the Info-Mac Archive as a page: a list of folders and files, each with a small icon. Click 00readme.txt to read the archive's welcome note.
