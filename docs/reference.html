Reference

Some servers answer one kind of question, and answer it well. This page introduces two: dictionary servers, which define words, and time servers, which tell your Macintosh the time. Mill speaks the protocols for both, with the plug-in described at the end of this page.

Dictionaries

A dictionary server keeps dictionaries and answers questions about the words in them. The protocol it speaks is called DICT. Its rulebook is RFC 2229, published in October 1997.

In the address, d: means define, and the word comes after it. Two other forms are useful:

  • m: in place of d: lists the words in the dictionaries that match the one you typed. It helps when you aren't sure of the spelling: dict://dict.org/m:modm finds modem.
  • Leave out d: and the word, as in dict://dict.org/, to see the list of dictionaries the server keeps.

The server dict.org keeps more than two hundred dictionaries: general English dictionaries, a thesaurus, dictionaries of computing terms such as the Jargon File, and dictionaries for translating between languages.

Try this

Type dict://dict.org/d:modem and press Return. Mill shows the definitions of modem from each of the server's dictionaries that has the word, with a box at the top for looking up another.

Time

A time server answers one question: what time is it? Many time servers are kept by national standards laboratories, whose work includes keeping their country's official time. The server time.nist.gov belongs to the National Institute of Standards and Technology, in the United States.

Two protocols ask for the time, and both were published in 1983:

  • The Time protocol (RFC 868) answers with a number: the seconds since the start of 1900. Mill compares it with your Macintosh's clock.
  • The Daytime protocol (RFC 867) answers with the date and time written out for people to read.

Mill asks for the Time protocol first. If a server offers only Daytime, Mill shows its answer instead.

The Time protocol counts the seconds in Coordinated Universal Time, the time kept by laboratories around the world, so Mill uses the Map control panel to turn it into your local time. If you haven't set the Map control panel to a city in your time zone, set it before you set the clock.

The Time protocol counts whole seconds, so after setting, your clock will be right to within a second or two.

Try this

Type time://time.nist.gov/ and press Return. Mill shows the server's time beside your Macintosh's, and how far apart they are. A button, Set this Mac's clock, sets your Macintosh's clock to match.

Good manners

Time servers answer a great many computers. Checking your Macintosh's clock once a day, or less often, is plenty.

What Mill needs

Dictionaries and time come with the Internet Services Plug-In, which Easy Install puts in. In Mill's Settings, each has a Default server: dict.org and time.nist.gov, unless you change them.

If you would rather not type these addresses, type plugin://internet-services/about for a small form that fills in the address for you.
