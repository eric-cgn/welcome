Searching

There are more places on the Internet than anyone could visit, and no one keeps a complete list of them. To find something, you can ask a search engine: a server that helps you find pages on other servers. You give it a few words, and it answers with a list of pages that match them. Each item in the list is a link.

Behind every search engine is an index, much like the index at the back of a book: you look up a word, and the index tells you where to turn. Unlike a book's index, a search engine's index changes as the pages it knows about change.

FrogFind

FrogFind is a search engine that also rewrites the pages it finds so a smaller computer can read them. Many pages are designed for more powerful computers with color screens. FrogFind keeps the main text of each page and sets it out plainly, so Mill can show it well. FrogFind is run by one person, who built it with Macintosh computers like yours in mind.

Tip

Search engines usually do best with a few particular words. To find a recipe for apple pie, try apple pie recipe rather than a whole question.

Try this
  1. Type http://frogfind.com/ in the address bar, and press Return.
  2. Click in the box beside "Web search," and type a word or two, such as Macintosh.
  3. Press Return.

FrogFind shows a list of pages that match. Click one, and FrogFind brings you its rewritten copy of that page. To search again, use the box at the top of the list.

Searching for simple pages

Wiby, at http://wiby.me/, is a search engine that lists pages built in a simple style, many of them made by people writing about what interests them. Wiby doesn't rewrite pages, so it sends you to each page as it is. Some of the pages it lists use encryption, and need the proxy described in The World Wide Web.

Searching Gopher

As you read in Gopher, a Gopher server offers menus instead of pages. Gopher has a search engine of its own, called Veronica-2, run at Floodgap.

Type gopher://gopher.floodgap.com/7/v2/vs and press Return. Mill shows a box labeled "Search for." Type a word, and press Return. Veronica-2 answers with a Gopher menu of the items it found, each one a link.

In a Gopher address, the 7 right after the server's name marks a search.
