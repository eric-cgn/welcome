Finding People

Every server on the Internet is kept by people, and many are used by people every day. Three protocols help you learn about them: finger, whois, and LDAP. Mill speaks all three, with the plug-ins described at the end of this page.

Finger

Try this
  1. Type finger://happynetbox.com/ and press Return. Mill shows a list of names: people who have written something for others to read with finger.
  2. Choose a name from the list. Type finger://happynetbox.com/ followed by the name, and press Return.

Mill shows what that person wrote.

Finger answers a simple question: who is this person? You send a person's name to a computer, and it answers with what that computer has been set up to share about them: often a real name, when they last connected, and a short note they wrote themselves, called a plan.

A plan is a little like a note pinned to an office door, except that anyone on the Internet can read it.

If you leave the name out, as in the first step above, many computers answer with a list of the people using them. Some computers answer finger requests. Many don't, to protect their users' privacy.

Happy Net Box, the server in the steps above, is run by Ben Brown for people who like to write a few lines for others to find.

Finger isn't only for people. The server graph.no answers with a weather chart, drawn in letters and symbols, for the town you name. Try finger://graph.no/oslo, or put the name of a town near you in place of oslo.

Finger was written by Les Earnest at Stanford University in 1971. Its rulebook is RFC 1288, published in 1991.

Whois

Try this

Type whois://whois.iana.org/edu and press Return. Mill shows who looks after the names that end in edu, and how to reach them.

Whois answers a different question: who is responsible for a name? A name such as 1in1e6.com is registered to the person or organization that uses it, and each group of names, such as com or edu, is looked after by an organization of its own. Whois servers keep these records and answer questions about them. (You read about groups of names in Names and Numbers.)

The server whois.iana.org answers for the groups themselves. Its answer for edu includes a line that begins whois:, naming the whois server for that group. To ask about a name in the group, use that server: type whois://, the server's name, a slash, and the name you are asking about.

Whois is described in RFC 954, published in 1985.

Directories

Try this
  1. Type ldap://db.debian.org/ and press Return. Mill lists the directories this server keeps.
  2. Click dc=debian,dc=org.

Mill shows the two entries inside it: one for the project's members (ou=users) and one for its computers (ou=hosts).

A directory is a list of people, and sometimes of things, kept on a server so that it can be searched. It is a little like a telephone book. Unlike a telephone book, a directory is arranged the way folders are on your Macintosh: each entry sits inside a larger one, and an entry's name lists the larger ones it sits inside, as in ou=hosts,dc=debian,dc=org.

LDAP, the Lightweight Directory Access Protocol, is a protocol for searching directories. Its rulebook is RFC 1777, published in 1995. It was designed as a lighter way to reach directories built to an earlier, larger standard called X.500.

Most directories are kept by schools and companies for their own people, and many answer only the computers on their own network. If yours has one, the people who run its network can tell you its server's name.

The directory in the steps above belongs to the Debian project, which makes a free operating system: software that does for other computers what the System does for your Macintosh. The project keeps a public directory of its members and its computers.

The first page Mill shows for a directory server also has a search form. Type the first letters of a person's name in the Name box, and click Search.

If a directory asks for a name and password, Mill asks you for them. They travel as plain text, so use a password you don't use anywhere else.

Good manners

The people in these records shared them so that others could find them when there is a reason to. Use what you find the way you would use a telephone book.

Whois servers answer a great many questions, and many limit how many they will answer from one computer. Ask only what you need.

What Mill needs

Finger and whois come with the Internet Services Plug-In, and directories with the LDAP Plug-In. Easy Install puts in both. To see the plug-ins Mill has, type mill://plugins.

If you would rather not type these addresses, type plugin://internet-services/about or plugin://ldap/about. Each has a small form that fills in the address for you.
